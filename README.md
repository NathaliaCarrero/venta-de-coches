# venta-de-coches
Proyecto sprint 7
La aplicación web sirve para explorar datos de anuncios de venta de coches. Dentro de esta podemos encontrar botones que nos permitirán crear histogramas con base al odómetro y gráficos de dispersión que corresponden a odómetro vs precio
